# Manual de Usuario - TMS Grúas

## Acceso al Sistema
- **URL**: Proporcionada por administrador
- **Roles**: Administrador, Supervisor, Operador, Cliente
- **Recuperación**: Función "Olvidé mi contraseña" disponible

## Módulos Principales

### 🚛 Servicios
- Crear y gestionar servicios de grúas
- Estados: Pendiente, Confirmado, En Proceso, Completado, Cancelado
- Asignación de recursos (grúas y operadores)
- Seguimiento en tiempo real

### 🏗️ Grúas
- Registro de flota completa
- Control de mantenimientos preventivos y correctivos
- Estados: Disponible, En Servicio, Mantenimiento, Fuera de Servicio

### 👷 Operadores
- Gestión de personal operativo
- Control de licencias y certificaciones
- Cálculo automático de comisiones
- Asignación inteligente de servicios

### 📦 Inventario
- Catálogo de productos y repuestos
- Control de stock con alertas automáticas
- Movimientos de entrada y salida
- Reportes de valorización

### 💰 Finanzas
- Gestión de costos operacionales
- Facturación automatizada
- Conciliación de pagos
- Reportes financieros

### 📊 Reportes
- Dashboard ejecutivo en tiempo real
- Análisis operacional
- Control de costos
- Métricas de mantenimiento

## Funcionalidades Móviles
- **PWA**: Instalable como app nativa
- **Offline**: Funcionalidades básicas sin internet
- **Geolocalización**: Seguimiento de servicios
- **Cámara**: Documentación fotográfica

## Portal del Cliente
- Solicitud de servicios
- Seguimiento en tiempo real
- Historial de facturas
- Dashboard personalizado
